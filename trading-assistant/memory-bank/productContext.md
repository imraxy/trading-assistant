# Product Context

- Users need accurate Bybit Futures position analytics with a modern, sortable/filterable grid and clear USD values. Support showing both Long and Short per symbol, deltas (1h/1d/1w), and risk hints.
- The dashboard should load open positions from Bybit mainnet only and optionally include closed PnL history.
- Debugging is supported via an in-app snapshot service to capture screenshots and logs quickly.
